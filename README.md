## 📖 About

This repository holds solutions I've written while practicing on **LeetCode**, split across **Python** and **C++**. Topics covered so far include arrays, strings, hashmaps, two pointers, binary search, linked lists, and sliding windows — with more added as I keep solving.

Each file is named `<problem-number>.<ProblemName>.<ext>`, so you can jump straight to a problem by its LeetCode number.

## 🚀 How to Use This Repo

1. **Browse by topic or number** — use the tables above, or search the file tree using GitHub's `Go to file` (press <kbd>T</kbd>) with the problem number.
2. **Clone it locally** if you'd rather run/test solutions on your machine:
   ```bash
   git clone https://github.com/hariharasudhan-29507/LEETCODE.git
   cd LEETCODE
   ```
3. **Compare approaches** — problems with multiple tags (e.g. `HashMap`, `Counter`, `recursive`) show more than one valid way to solve the same problem.
